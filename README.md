# AI-Powered Phishing Detection and Prevention System

An AI-powered cybersecurity system designed to automatically detect phishing and malicious emails.

## Features

- Gmail email monitoring
- Automated workflow using n8n
- URL and attachment analysis
- VirusTotal threat intelligence
- AI-based phishing detection
- Risk scoring system
- Gmail threat indicators
- Detailed security dashboard

## Proposed Architecture

Gmail → n8n → Security Analysis → VirusTotal + OpenAI → Risk Scoring → Database → Dashboard

## Technologies

- n8n
- Gmail API
- Python
- FastAPI
- React
- PostgreSQL
- VirusTotal API
- OpenAI API
- Chrome Extension
